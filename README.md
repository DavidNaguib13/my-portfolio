## Run locally
Open `index.html` in a browser. No build step, no dependencies. Fonts load from Google Fonts and fall back to system fonts offline.

## Deploy on GitHub Pages
1. Create a public repository named `portfolio` (or `YOUR-USERNAME.github.io` for a root URL).
2. Upload `index.html`, `.nojekyll` and `README.md`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
4. Wait about a minute, then open the URL shown on that page.
